## Основные проекты

### [Telyra](https://github.com/EvgenyPonomarevNova/telyra)

**Сервис запущен: [telyra.ru](https://telyra.ru).** Онлайн-запись для мастеров: персональная страница, услуги, расписание, календарь и клиенты. Клиент записывается через браузер; Telegram подключается по желанию.

Next.js · React · TypeScript · Payload CMS · PostgreSQL · Docker.

### [Архив дел](https://github.com/EvgenyPonomarevNova/archive-of-cases)

**В разработке.** Кооперативные расследования: общий экран для команды, личные улики на телефонах, синхронизация событий и восстановление состояния. Реализовано одно дело с режимами на 2–3 игроков.

Next.js · React · TypeScript · Socket.IO · PostgreSQL · Three.js.

Оба репозитория — публичные витрины с описанием и архитектурой. Рабочие исходники остаются приватными.
